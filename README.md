# 정보기술전공심화 동아리 퀴즈 🎉

대진전자통신고등학교 동아리의 날 실시간 퀴즈 (카훗 스타일)

- **참가자 페이지**: `https://내주소.vercel.app/` → QR 찍고 닉네임 입력
- **관리자 페이지**: `https://내주소.vercel.app/admin` → 비밀번호 `1234`

---

## 1단계. Firebase 만들기 (5분, 무료)

1. https://console.firebase.google.com 접속 → 구글 로그인 → **프로젝트 만들기**
   - 이름 아무거나 (예: `daejin-quiz`), 애널리틱스는 꺼도 됨
2. 왼쪽 메뉴 **빌드 → Realtime Database** → **데이터베이스 만들기**
   - 위치: **싱가포르 (asia-southeast1)** 추천
   - 보안 규칙: **테스트 모드로 시작**
3. Realtime Database 화면 위쪽 **규칙(Rules)** 탭 → 아래 내용으로 바꾸고 **게시**
   (테스트 모드는 30일 뒤 막히니까 이걸로 바꿔두는 게 안전해요. `database.rules.json`과 같은 내용)
   ```json
   {
     "rules": {
       ".read": true,
       "game": { ".write": true },
       "players": { ".write": true },
       "answers": { ".write": true },
       "presence": { ".write": true }
     }
   }
   ```

## 2단계. 설정값 붙여넣기

1. Firebase 콘솔 → 톱니바퀴 ⚙️ **프로젝트 설정** → 아래쪽 **내 앱** → **웹(`</>`) 아이콘** 클릭
2. 앱 이름 아무거나 입력 → 등록 (Firebase 호스팅 체크 ❌)
3. 나오는 `firebaseConfig = { ... }` 값을 **`firebase-config.js`** 에 그대로 덮어쓰기
   - `databaseURL` 이 꼭 있어야 해요! 없으면 Realtime Database 화면 상단의 `https://....firebasedatabase.app` 주소를 복사해서 넣기

## 3단계. Vercel 배포

**방법 A — GitHub로 (추천)**
1. GitHub에 새 저장소 만들고 이 폴더의 파일 전부 업로드
2. https://vercel.com → **Add New → Project** → 그 저장소 **Import** → 설정 건드리지 말고 **Deploy**

**방법 B — 터미널로**
```bash
cd 이폴더
npx vercel --prod
```

배포 끝나면 나오는 주소(`https://xxx.vercel.app`)가 참가 주소예요.

## 4단계. 당일 진행 순서

1. 관리자 컴퓨터(빔프로젝터 연결)에서 `/admin` 접속 → 비밀번호 `1234`
2. 화면에 뜬 **QR**을 사람들이 찍고 닉네임 입력 → 오른쪽에 이름이 뜸
   - 상단 **QR 크게** 버튼 누르면 QR만 크게 보여줘요
3. 다 모이면 **퀴즈 시작 ▶**
4. 문제마다 20초. **전원이 답하면 바로** 정답 공개, 아니면 20초 끝나고 공개
5. 정답 공개 화면에서 8초 뒤 자동으로 다음 문제 (체크 끄면 **다음 문제 ▶** 버튼으로 직접 넘김)
6. 12문제 끝나면 🥇🥈🥉 시상대 + 전체 순위
7. 다음 팀 받을 때:
   - **점수 초기화** → 같은 사람들로 다시 하기
   - **참가자 전체 삭제** → 새로운 사람들 받기 (동아리의 날엔 보통 이거!)

### 점수 계산
- 정답: 빨리 맞힐수록 높음 (최대 1000점 ~ 최소 500점)
- 오답·시간초과: 0점

---

## 문제 수정하기

`questions.js` 만 고치면 돼요.

```js
{ type: "mc", q: "문제", options: ["보기1", "보기2", "보기3", "보기4"], answer: 1 },  // answer는 0부터 (1 = 두 번째 보기)
{ type: "ox", q: "문제", answer: 0 },  // 0 = O, 1 = X
```
고친 뒤 GitHub에 다시 올리면 Vercel이 자동으로 재배포해요.

제한시간·자동 진행 시간·비밀번호도 `questions.js` 맨 위에서 바꿀 수 있어요.

## 참고
- 비밀번호는 간단한 잠금이에요. 관리자 주소(`/admin`)는 참가자들한테 알려주지 마세요.
- 폰 화면이 꺼졌다 켜져도 같은 닉네임·점수로 자동 복귀돼요.
- 테스트는 폰 2~3대로 미리 한 판 돌려보는 걸 추천해요!
